# Hybrid RAG workbench: portfolio demo

## Intent
A short demo for the portfolio, published next to the report page
(https://claude.ai/artifact/8DhAe29yjjX9gPhmFzfzBv). "Each determined and tech flow, evaluation testing should be
explained in detail but simple short video." Upload a document, ask a question, explain each section of the UI and
how it is used.

## Customizations
- Feature the app's own captured screens (http://localhost:8501) as the video's assets.
- Look matches the restyled app: pale, formal, light only (user: "never prefer dark theme anywhere"), bold modern
  fonts, glowing borders, numbers and graphs that move.
- Scene plan confirmed by the user: title → upload & ingest → ask → answer → vector → graph → tech flow →
  evaluation → testing & close.
