Portfolio · Retrieval-augmented generation

Hybrid RAG Engine

A question-answering service over PDFs that indexes each document twice: as vectors in FAISS and as a knowledge graph in NetworkX. Both retrievers run on every question. Their evidence is fused into one prompt, and NeMo Guardrails checks the input and the answer. Every answer comes back with the evidence that produced it.

How it works

Two indexes, one answer

Ingestion builds both indexes from the same chunks. Each graph fact keeps the id of the chunk it came from, so the two retrievers can agree on a passage and every fact traces back to real text.

Shared chunk ids

A passage that both retrievers return gets a +0.10 score boost. Up to 3 passages that only the graph found are added as extra evidence.

Entity linking

Question terms map to graph nodes by exact name, partial name, then embedding similarity (threshold 0.55), and expand 1 hop.

Fail closed

If the rail model itself errors, the request is blocked. Blocked or empty-context questions never reach the answer model.

Strong

Grounded and complete

Faithfulness, answer relevancy and contextual recall are 1.0 in both modes. Every answer stayed inside the retrieved evidence and the evidence always held the reference fact.

Next fix

Too much context per question

Contextual relevancy is about 0.1. With top-k 5 over a 6-chunk document, nearly the whole file reaches the prompt for single-fact questions. A score cut-off or a re-ranker would trim it.

Next fix

Graph passages dilute ranking

Hybrid precision is 0.62 against 1.0 for vector-only, because graph-sourced passages can rank above the best vector hit. On a document this small the graph adds little. It is built for multi-document, multi-hop questions.

Layered backend

Tested without keys

77 tests run real FAISS, NetworkX, PyMuPDF, NeMo config, DeepEval metrics, FastAPI and Streamlit AppTest against fake LLMs and a deterministic embedder.

Operable

Ingestion and evaluation run as background jobs that the UI polls. The service runs under Docker Compose, can switch between OpenAI and Anthropic, and links LangSmith traces to evaluation scores.
